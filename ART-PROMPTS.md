# Art prompts for the Claude version

Nine original images. Each one is a new scene, not a copy of the Codex pictures.
Make each image in ChatGPT (or Gemini), download it, and save it in
`claude-code-silver-app-version/assets/art/` with the file name shown.
Then tell Claude, and Claude will shrink the files and put them in the site.

## Style line (already inside every prompt below)

Pixar-style 3D animated film still, soft global illumination, warm natural
light, gentle subsurface skin, friendly rounded proportions, expressive eyes,
kind smile, high detail, clean composition. Malay Muslim older people from
Kedah, Malaysia: men wear a kopiah or songkok and baju Melayu; women wear a
tudung and baju kurung. Colour harmony: warm milk white, olive green, midnight
blue, walnut wood, a touch of terracotta. No text, no letters, no logos, no
watermark.
